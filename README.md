# Bảo Anh IT - Fullstack Developer Portfolio 🚀

A modern, responsive, high-performance developer portfolio built with **React**, **TypeScript**, **Vite**, and **Sass**, featuring a cyber-obsidian frosted glassmorphism design system.

---

## 🌟 Key Features

- **Design System**: Frosted Glassmorphism, Aurora Glow mesh, customized CSS custom properties.
- **Dark & Light Mode**: Seamless theme switcher with persistent local storage state.
- **Internationalization (i18n)**: Full multi-language support (English 🇬🇧 / Tiếng Việt 🇻🇳).
- **Hero IDE Code Editor**: VS Code-inspired macOS terminal mockup with syntax highlighting and 1-click code copying.
- **Stats & Metrics**: Key career highlights and milestones with 3D Parallax Tilt interaction.
- **Skills Showcase**: Grouped filter tabs (Frontend, Backend, Tools) paired with a smooth infinite marquee.
- **Career Timeline**: Glowing vertical timeline highlighting professional experience and academic background.
- **Featured Projects**: Filterable project cards with mockups, tech badges, live demo, and source code links.
- **Interactive Contact**: Quick messaging form and direct 1-click email copy action.
- **Performance & SEO**: Optimized fonts, responsive mobile drawer navigation, and clean bundle output.

---

## 🛠️ Tech Stack

- **Core**: React 18, TypeScript, Vite
- **Styling**: Vanilla SCSS / CSS Custom Properties, React Bootstrap
- **Icons & Animation**: React Icons, Lottie React, Typewriter Effect, React Parallax Tilt, React Fast Marquee
- **Internationalization**: i18next, react-i18next
- **Routing**: React Router v7

---

## 🚀 Getting Started

### 1. Installation

```bash
npm install
```

### 2. Run Development Server

```bash
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### 3. Build for Production

```bash
npm run build
```
